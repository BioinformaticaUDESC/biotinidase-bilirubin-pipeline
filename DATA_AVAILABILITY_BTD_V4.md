# Data and code availability — manuscript V4

Prepared by Juan Philippe Teixeira on 16 November 2026.

## Manuscript-ready statement

Post-processing scripts and complementary derived numerical data for this study are publicly available at https://github.com/BioinformaticaUDESC/biotinidase-bilirubin-pipeline. The complementary source archive deposited at commit 8daa414ea004002a261f73848eb6d81e00fd7053 contains the shared PCA mean, fitting reference and eigenvectors, per-frame PC1–PC2 projections, FEL histogram counts and relative energies, Rg/SASA and receptor–ligand proximity series, MM/PBSA input files and per-frame results for the common 50–200 ns interval and system-specific cluster intervals, residue-decomposition summaries, and source-provenance records. Original molecular dynamics trajectories, full production TPR files, and complete simulation topologies are not included. The deposited files support verification of the exported post-processing results but do not permit an independent rerun of the original simulations.

The original V3 export filename is retained for provenance. This is the source-data export used for the complementary analyses in manuscript V4; it is distinct from the separately assembled SupplementaryData1_BTD_V4.zip manuscript supplement. Source-figure layouts were subsequently revised for V4, while numerical data were preserved. The PCA/FEL results package is nested inside the source ZIP and must be extracted separately.
